# Breach Protocol

A browser-based tactical FPS built with Three.js — single HTML file, no build step.

Play it live: (link added after first deploy)

## Features
- 5 maps with real verticality (stairs, platforms, tunnels) and varied textures
- 5 weapons (pistol, SMG, AR, shotgun, sniper w/ scope) with pickups and per-round progression
- AI bots with difficulty that scales round over round
- Multiplayer: host or join a 2-player co-op vs bots, or 1v1 PvP — peer-to-peer via WebRTC, no server required

## Running locally
Just open `index.html` in a browser, or serve the folder with any static file server.
